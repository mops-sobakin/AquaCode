# AquaCode

Минималистичный редактор кода с AI-помощником.

## Как использовать

1. Скачайте `index.html`
2. Откройте в браузере
3. Создавайте файлы и папки через проводник слева

## Что умеет

- Файловый проводник с деревом папок
- Создание, переименование, удаление файлов
- Редактор кода с табами и номерами строк
- AI-чат с ответами на русском и английском
- 2 темы: тёмная и светлая
- Переключение языка интерфейса
- Горячие клавиши: Ctrl+S, Tab

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| Ctrl+S | Сохранить |
| Tab | Отступ |
| Ctrl+Z | Отменить |
| Ctrl+C | Копировать |
| Ctrl+V | Вставить |

## Технологии

HTML, CSS, JavaScript. Никаких зависимостей.
