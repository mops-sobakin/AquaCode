# Aqua Code V1

Современный веб-редактор кода с AI-помощником.

## Быстрый старт

1. Скачайте файл `index.html`
2. Откройте в браузере (Chrome, Firefox, Edge)
3. Готово!

**Никаких зависимостей. Никакой установки. Просто откройте файл.**

## Возможности

### Редактор
- Открытие файлов по клику в проводнике
- Табы для нескольких файлов одновременно
- Номера строк
- Подсветка синтаксиса (автоматически для .js, .html, .css, .json)
- Сохранение изменений (Ctrl+S)

### Проводник
- Дерево файлов и папок
- Создание новых файлов и папок
- Переименование и удаление
- Поиск файлов по имени
- Контекстное меню (правый клик)

### AI-чат
- Ответы на русском и английском языках
- Помощь с кодом, ошибками, рефакторингом

### Настройки
- **3 темы**: Dark (космос), Aqua (океан), White (минимализм)
- **Локализация**: Русский / Английский
- **Редактор**: Размер шрифта, табуляция
- **AI**: Температура, автодополнение, ошибки, рефакторинг

### Горячие клавиши
- `Ctrl+S` — Сохранить файл
- `Tab` — Вставить отступ (2 пробела)
- `Ctrl+Z` — Отменить
- `Ctrl+Y` — Повторить
